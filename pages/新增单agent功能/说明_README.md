# Agent Studio 演示包 · 说明

## 一、怎么跑

从项目根目录打开 `index.html`，会进入统一的 `prototype-shell.html`。如果只演示 Agent 模块，也可以直接打开下面的页面：

```
agent开发页面原型.html          ← Agent 应用配置页
Agent_Studio_智能体编辑器_dc.html ← ② 智能体编辑器（点“新建/查看”跳转到这里）
support.js                       ← ③ 编辑器的运行时（②依赖它，勿删）
```

> ⚠️ **编辑器页面首次加载需要联网**：`Agent_Studio_智能体编辑器_dc.html` 通过
> support.js 从 unpkg CDN 拉取 React / Babel 后再渲染（这是该文件原本的机制，未改动）。
> 内网评审如无外网，请提前把 React/ReactDOM/Babel 换成本地文件，或在有网环境演示。
> 原型页 `agent开发页面原型.html` 无任何外链，纯离线可跑。

## 二、演示动线

1. 打开项目根目录的 `index.html` → 统一平台壳层 → 应用配置页（默认页）。
2. 点右上「新建应用」→ 弹窗 → 填名称 → 点弹窗里的「新建」→ **跳转到智能体编辑器**。
   （列表里每行的「查看」也会跳到同一个编辑器。）
3. 编辑器页：统一壳层自动进入**沉浸式工作台**，左侧平台导航收起，编辑器内容铺满整个窗口。
4. 点编辑器**左上角的 ⌂ 按钮** → **返回统一壳层的应用配置页**。

统一壳层的导航和路由由同目录下的 `prototype-routes.js`、`prototype-nav.js` 和 `prototype-shell.css` 维护；功能页进入壳层时会隐藏自身的平台侧栏，保留业务内容和页面级操作。

## 三、改了什么

### `Agent_Studio_智能体编辑器_dc.html`（只改布局与跳转，功能不动）
- 左侧平台导航栏 `display:none` 收起；右侧内容用原有 `flex:1` 自动铺满整窗。
  导航 DOM 与其事件全部保留，只是隐藏，不影响任何功能。
- 左上角 ⌂ 按钮：原来只弹提示，现改为跳回 `agent开发页面原型.html`。
- MCP/Tool 详情页的「返回」按钮：原来回到「MCP 接入/Tool 工具」列表页
  （那两个列表页只能靠已隐藏的左侧导航返回，会走进死路），现统一改为「返回应用设置」
  直接回编辑器，保证导航闭环、无断头路。这是收起导航后必须做的连带处理。
- 编辑器的模型/角色指令/技能/工具/变量/同义词/对话/发布等**全部原有功能保持不变**。

### `agent开发页面原型.html`（对齐编辑器风格 + 修交互 bug）
导航栏风格向编辑器看齐：深蓝底 `#0d1a36`、金色 EBC Logo、扁平选中态 `#20305a`、
MVP 徽标 `#f5b93c`、蓝色头像 `#2b5fd9`。

修复的交互问题：
- 「新建」原来只关弹窗、不跳转 → 现校验名称后跳编辑器。
- 左侧导航分组的展开箭头原来点了没反应（无 JS）→ 现可正常展开/收起，
  且「能力与工具中心」默认展开（与编辑器一致）。
- 删除确认弹窗原来写死显示「…应用02」，删第 2 行也显示 02 → 现按所在行动态取真实应用名。
- 删除、导入应用、使用文档、复制、图标上传等原本点了无反应的按钮 → 现均有轻提示反馈。
- 「了解更多」链接原为 `href="#"`（会把弹窗滚到顶）→ 已改为不跳转。
- 名称/简介字数统计进入时先同步一次。

> 原型底部的「后端交底标注层（蓝色泡泡）引擎/样式/数据」**一字未动**（已逐字节比对确认），
> 打开原型页照常出现右下角「后端标注」工具条与泡泡。

## 四、文件命名注意
三个文件名（含中文）请保持不变；跳转是按这三个文件名相对寻址的，改名需同步改跳转地址。
